# C++ OOP Assignment

## 📌 About This Project

This project contains C++ programs developed to practice **Object-Oriented Programming (OOP)** concepts. The assignment includes two programs based on classes, objects, constructors, function overloading, and member functions.

## 📚 Programs Included

### 1. Product Management System

The first program creates a `Product` class with:

* Product ID
* Product Name
* Price
* Private data members
* `setData()` function overloading
* Product information display
* `for` loop for multiple products

The program demonstrates how the same `setData()` function can perform different tasks depending on the number of arguments.

### 2. Bank Account Management System

The second program creates a `BankAccount` class with:

* Account Number
* Account Holder
* Account Type
* Balance
* Default constructor
* Parameterized constructors
* Constructor overloading
* Deposit operation
* Withdrawal operation
* Account information display
* Destructor

It also demonstrates different constructors and the order in which destructors are called when objects are destroyed.
